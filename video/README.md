# סרטון ההדרכה של למדתי

סרטון של 35 שניות שמראה איך משתמשים באתר. ארבעה צעדים, ולכל אחד כיתוב קצר אחד:
1. **שואלים במילים שלכם:** ארבע השורות במחברת.
2. **ציון רק מבוגרים מאומתים:** בוחרים את הקורס הראשון ברשימה, נכנסים, ורק שם הציון.
3. **שואלים שאלה, והיועץ עונה:** שאלה בשורה הראשונה, והתשובה מעל הרשימה, כל משפט בצבע של המקור שלו.
4. **הצבע אומר מה המקור:** מקרא הצבעים, מיד אחרי התשובה שהצבעים סימנו.

**למה קצר:** אנשים מוותרים אחרי 20 שניות (גל, 14.11.2026). לכן הליבה (שואלים, רשימה, ציון) נגמרת בערך בשנייה 18, וכל כיתוב נשאר על המסך כל הסצנה, כדי שיהיה זמן לקרוא אותו.

שתי גרסאות מאותו קוד:
- **16:9** (1920x1080) לאתר;
- **9:16** (1080x1920) לוואטסאפ ולרשתות.

הפרויקט נפרד מ-`web/`, ולא משנה את הבנייה של האתר.

## איך זה בנוי

- **הצילומים:** `scripts/capture.mjs` פותח את האתר החי ב-Playwright, במחשב (1440x810) ובטלפון (390x844).
  - **מה הוא עושה:** ממלא את ארבע השורות. מקליד "לבנות אתרים" אות אחר אות, בוחר "להחליף מקצוע", "ערבים" ו"אונליין", ומקליד "15000".
  - **מה הוא שומר:** ב-`meta.json`, איפה כל רכיב חשוב נמצא. "ההשוואה שלי" פתוחה רק למחוברים, ולכן הסקריפט מצייר את אותו רכיב (`CompareTray`), באותן מחלקות, בתוך עמוד חי.
- **היועץ:** `scripts/capture-advisor.mjs` מצלם בנייה מקומית, לא את האתר החי.
  - **הבנייה:** עם מפתח מזויף בפקודה עצמה בלבד: `ANTHROPIC_API_KEY=fake pnpm --dir web build`, ואז `next start -p 3100`. המפתח לא נכתב לשום קובץ.
  - **התשובה:** `/api/advise` מוחלף בתשובה מ-`scripts/advisor-mock.json`, כמו ב-`web/e2e/advisor.spec.ts`. היא בנויה רק מעובדות לדוגמה שבעמוד של פיתוח Full Stack, כל אחת עם המקור שלה.
- **מקרא הצבעים:** `legend/index.html` היא קומפוזיציה של [HyperFrames](https://github.com/heygen-com/hyperframes). המשיכות, הצבעים והמספרים המוקפים הועתקו מ-`web/src/app/globals.css`. היא מרונדרת ל-`public/legend/legend.mp4`, שנשמר במאגר.
- **ההרכבה:** Remotion (`src/`). שולחן בהיר ושטוח, כרטיס הסבר בעט כחול, ודף עם "מצלמה" שזזה על הצילומים. העט מקיף ומסמן בדיוק את הרכיבים מ-`meta.json`. הפונטים והצבעים כמו באתר אחרי הרענון (DESIGN.md): IBM Plex Sans Hebrew לדיו, Rubik לעט, והלוגו עם ה-ל המוקפת.

כל הנתונים בסרטון הם נתוני הדוגמה של האתר, וזה כתוב בו (סלוטייפ "לדוגמה" על הדף, ושורה בפתיחה ובסיום).

## הרצה

```bash
pnpm install --ignore-workspace
pnpm shots     # מצלם את האתר החי לתוך public/shots (בערך 2 דקות)
pnpm legend    # רק אם שיניתם את legend/index.html
pnpm render    # שני ה-MP4 לתוך out/
pnpm studio    # עורך חזותי של Remotion, לתיקונים
```

- **פריימים בודדים לבדיקה:** `node scripts/stills.mjs wide 80 157` (או `tall`), לתוך `out/stills`.
- **הכתובת בסוף הסרטון:** `URL` ב-`src/Root.tsx`. כשהדומיין של למדתי יעבוד, מחליפים שם ומרנדרים שוב.
- **HyperFrames בלי טלמטריה:** `scripts/render-legend.mjs` מריץ אותו עם `HYPERFRAMES_NO_TELEMETRY=1` ו-`DO_NOT_TRACK=1`.
