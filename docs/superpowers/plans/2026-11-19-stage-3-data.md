# "לא יודעים למי לפנות?", שלב 3: הנתונים. תוכנית בנייה

> **למי שמבצע:** עובדים משימה אחר משימה, לפי הסדר (superpowers:executing-plans או superpowers:subagent-driven-development). כל צעד מסומן ב-checkbox. הכול בענף `plan-1-foundation`, בלי להחליף ענף.

**Goal:** לבנות את שלב 3 של מסמך העיצוב `docs/superpowers/specs/2026-11-17-who-to-turn-to-design.md` ("שלב 3: הנתונים"), לפי `docs/research/2026-11-17-missing-course-data.md`:
- **מיקום לפי המוסד:** עיר למוסד (`institutions.city`), ו"מיקום" בעובדות שנלקח ממנה, עם "לפי כתובת המוסד". מוסד שמלמד רק אונליין נותן "אונליין", עם "לפי המוסד".
- **חילוץ טוב יותר באוסף:** "אונליין", "בזום" ו"מקוון" הם אזור; רשימת ערים נשארת כמו שהיא; "היברידי" הוא מתכונת; שבועות הופכים לחודשים; ומספר המפגשים נשמר בעמודה חדשה (`courses.session_count`).
- **"משולב" ו"מוקלט" באתר,** כך שהרשימות ועמוד הקורס מסכימים.
- **חילוץ מחדש של כל הקורסים שבאתר,** ושדה ריק שהתמלא עולה לבד.
- **מקורות חדשים** ב-`scraper/institutions.yaml`.

**Architecture:**
- **המסד שומר על הכללים:** מיגרציה אחת מוסיפה את `institutions.city` (פתוחה לציבור), את `courses.session_count`, בדיקה על `courses.formats`, ואת `session_count` לרשימה הסגורה של `private.scraper_set_course_field`.
- **האוסף:** ההנחיה והסכמה (`fields.py`, `extract.py`) קובעות איך כותבים אזור, מתכונת, משך ומפגשים. ההמרה של שבועות לחודשים והאיחוד של "אונליין" נעשים בקוד, בפונקציות טהורות, ולא במודל.
  - **ההחלטה מה עולה לבד** (`decide.py`) מקבלת כלל אחד חדש: שדה שהיה ריק.
  - **הריצה** (`run.py`) מקבלת דגל לחילוץ מחדש.
- **האתר:** `web/src/lib/course/facts.ts` נשאר מקור האמת של "מיקום". התיבה, השורה ברשימות, הסדר, השאלות ותמונת השיתוף קוראים רק לו. `search/types.ts` מפריד בין המתכונות שבמסד (ארבע) לבין מה שאפשר לבחור בחיפוש (שתיים).
- **הנתונים של הערים:** סקריפט קטן הופך את המחקר (`docs/research/2026-11-19-institution-cities.csv`) לקובץ תיקון ב-`supabase/fixes/`.
  - **מה לא עושים כאן:** הקובץ לא רץ בענן בתוכנית. הוא רק נכתב.
- **מחיר:** בלי עמודה חדשה (החלטה 4, למטה).

**Tech Stack:** Python 3.12 עם uv ו-pytest (האוסף), Supabase (Postgres, pgTAP) על ה-Pi דרך `scripts/pi-db.mjs`, Next.js 16 עם React 19 ו-TypeScript, Vitest, ו-GitHub Actions (`scraper-weekly.yml`).

```python
def normalize_region(text: str) -> str:
    """אזור כמו שהמודל כתב, עם "אונליין" אחד לכל הדרכים לכתוב אותו ("בזום", "Zoom", "מקוון"). רשימת ערים נשארת כמו שהיא."""
    out: list[str] = []
    for part in (p.strip() for p in text.split(",")):
        if not part:
            continue
        word = ONLINE if part.casefold() in _ONLINE_WORDS else part
        if word not in out:
            out.append(word)
    return ", ".join(out)


def weeks_to_months(weeks: float) -> float | None:
    """משך בשבועות לחודשים, בחצאי חודש. פחות מ-MIN_WEEKS: None (אין משך בחודשים)."""
    if weeks < MIN_WEEKS:
        return None
    return max(0.5, round(weeks / WEEKS_PER_MONTH * 2) / 2)
```

```ts
 * עם תווית המקור "לפי כתובת המוסד". מוסד שמלמד רק אונליין נותן "אונליין", עם "לפי המוסד".
 */

/** הסדר בתיבה. */
export const FACT_KEYS = ['price', 'duration', 'format', 'location', 'certificate', 'nextCohort'] as const;
export type FactKey = (typeof FACT_KEYS)[number];

/** מה שצריך מקורס. גם CourseSummary (הרשימות) וגם CoursePageData (עמוד הקורס) מתאימים. */
export interface FactSource {
  sitePrice: number | null;
  totalHours: number | null;
  durationMonths: number | null;
  formats: readonly string[];
  region: string | null;
  /**
   * העיר של המוסד (institutions.city), או "אונליין" למוסד שמלמד רק אונליין. null: כמה סניפים, או שלא מצאנו.
   * משמשת רק כשהקורס עצמו לא כותב איפה הוא.
   */
  institutionCity: string | null;
  certificate: string | null;
  nextCohortDate: string | null;
}

/**
 * עובדה ידועה: הטקסט והמקור שלו. claim: המוסד אומר (קו כחול). verified: נבדק (ירוק).
 * note: תווית מקור קטנה ליד הערך, כשהוא לא בא מהדף של הקורס ("לפי כתובת המוסד").
 * עובדה חסרה: מה כותבים במקום (עיקרון 3, "מה שלא ידוע, כתוב").
 */
export type Fact =
  | { key: FactKey; label: string; known: true; text: string; source: 'claim' | 'verified'; note?: string }
  | { key: FactKey; label: string; known: false; missing: string };

export const FACT_LABEL: Record<FactKey, string> = {
  price: 'מחיר',
  duration: 'משך',
  format: 'מתכונת',
  location: 'מיקום',
  certificate: 'תעודה',
  nextCohort: 'מחזור הבא',
};

export const NOT_WRITTEN = 'לא כתוב בדף';
export const NO_PRICE = 'המוסד לא מפרסם מחיר';
/** בשורה הקצרה ברשימה (מסמך העיצוב, "הרשימות ועמודי התחומים"). */
export const NO_PRICE_SHORT = 'מחיר לא מפורסם';
/** המיקום של קורס שנלמד אונליין. אותה מילה כמו ב-courses.region וב-institutions.city. */
export const ONLINE = 'אונליין';
/** מיקום שבא מהעיר של המוסד, ולא מהדף של הקורס. */
export const BY_INSTITUTION_ADDRESS = 'לפי כתובת המוסד';
/** "אונליין" שבא מהמוסד (מוסד שמלמד רק אונליין), ולא מהדף של הקורס. */
export const BY_INSTITUTION = 'לפי המוסד';

/** המילים של כל מתכונת (search/types.ts). ערך שהקוד לא מכיר לא מוצג. */
const FORMAT_WORDS = new Map<string, string>(Object.entries(FORMAT_LABEL));
/** מתכונות בלי מקום. קורס שכולו כאלה נלמד אונליין, וזה המיקום שלו. */
const REMOTE = new Set(['online', 'recorded']);

/** טקסט מהמסד בלי רווחים בקצוות. טקסט ריק נחשב חסר. */
function present(text: string | null): string | null {
  const trimmed = text?.trim() ?? '';
  return trimmed === '' ? null : trimmed;
}

function durationText(c: FactSource): string | null {
  const parts: string[] = [];
  if (c.durationMonths !== null) parts.push(c.durationMonths === 1 ? 'חודש אחד' : `${c.durationMonths} חודשים`);
  if (c.totalHours !== null) parts.push(`${c.totalHours} שעות`);
  return parts.length > 0 ? parts.join(', ') : null;
}

function formatWords(c: FactSource): string[] {
  return c.formats.flatMap((f) => FORMAT_WORDS.get(f) ?? []);
}

function formatText(c: FactSource): string | null {
  const words = formatWords(c);
  return words.length > 0 ? words.join(' או ') : null;
}

/** איפה הקורס, ומאיפה זה ידוע. note: null כשזה מהקורס עצמו (האזור, או מתכונות בלי מקום). */
interface Place {
  text: string;
  note: string | null;
}

function placeOf(c: FactSource): Place | null {
  const region = present(c.region);
  if (region) return { text: region, note: null };
  const known = c.formats.filter((f) => FORMAT_WORDS.has(f));
  if (known.length > 0 && known.every((f) => REMOTE.has(f))) return { text: ONLINE, note: null };
  const city = present(c.institutionCity);
  if (city === null) return null;
  if (city !== ONLINE) return { text: city, note: BY_INSTITUTION_ADDRESS };
  // מוסד שמלמד רק אונליין, אבל הקורס הזה כותב שהוא בכיתה או משולב: לא מנחשים.
  return known.length > 0 ? null : { text: ONLINE, note: BY_INSTITUTION };
}

function fact(key: FactKey, text: string | null, source: 'claim' | 'verified' = 'claim', note: string | null = null): Fact {
  const label = FACT_LABEL[key];
  if (text === null) return { key, label, known: false, missing: key === 'price' ? NO_PRICE : NOT_WRITTEN };
  return note === null ? { key, label, known: true, text, source } : { key, label, known: true, text, source, note };
}

/**
 * שש העובדות, בסדר של FACT_KEYS.
 * המשך (חודשים ושעות) בירוק, כמו ב"על הקורס", בהשוואה ובהנחיות של היועץ. כל השאר טענה של המוסד, בקו כחול.
 */
export function courseFacts(c: FactSource): Fact[] {
  const place = placeOf(c);
  return [
    fact('price', c.sitePrice === null ? null : formatIls(c.sitePrice)),
    fact('duration', durationText(c), 'verified'),
    fact('format', formatText(c)),
    fact('location', place?.text ?? null, 'claim', place?.note ?? null),
    fact('certificate', present(c.certificate)),
    fact('nextCohort', c.nextCohortDate === null ? null : formatHebrewDate(c.nextCohortDate)),
  ];
}

/**
 * כמה מששת השדות ידועים. ממנו מתחיל הסדר ברשימות (search/match.ts, compareCourses).
 * בלי לעצב מחירים ותאריכים: המיון קורא לזה אלפי פעמים. הבדיקה מוודאת שזה מסכים עם courseFacts.
 */
export function knownFactsCount(c: FactSource): number {
  return [
    c.sitePrice !== null,
    durationText(c) !== null,
    formatText(c) !== null,
    placeOf(c) !== null,
    present(c.certificate) !== null,
    c.nextCohortDate !== null,
  ].filter(Boolean).length;
}

export interface LinePart {
  key: 'price' | 'duration' | 'format' | 'location';
  text: string;
}

/**
 * השורה הקצרה ברשימה, לקורס בלי ביקורות (מסמך העיצוב, "הרשימות ועמודי התחומים"):
 * מחיר או "מחיר לא מפורסם", משך, מתכונת ומיקום, ורק מה שידוע.
 * מיקום: מה שהקורס כותב, אלא אם המתכונת כבר אומרת אותו ("אונליין" לא נכתב פעמיים). "אונליין" שבא רק מהמתכונת
 * לא נכתב בכלל. מיקום מהמוסד נכתב עם המקור שלו בסוגריים, כי בשורה אין מקום לתווית נפרדת.
 */
export function factsLine(c: FactSource): LinePart[] {
  const parts: LinePart[] = [{ key: 'price', text: c.sitePrice === null ? NO_PRICE_SHORT : formatIls(c.sitePrice) }];
  const duration = durationText(c);
  if (duration) parts.push({ key: 'duration', text: duration });
  const format = formatText(c);
  if (format) parts.push({ key: 'format', text: format });
  const place = placeOf(c);
  if (place?.note) parts.push({ key: 'location', text: `${place.text} (${place.note})` });
  else if (place && present(c.region) !== null && !formatWords(c).includes(place.text)) {
    parts.push({ key: 'location', text: place.text });
  }
  return parts;
}
```

```python
"""הופך את המחקר על הערים של המוסדות לקובץ SQL שמעדכן את institutions.city (שלב 3, החלטה 1).

הרצה (מ-scraper/):
  uv run python -m tools.cities_to_sql ../docs/research/2026-11-19-institution-cities.csv ../supabase/fixes/2026-11-19-institution-cities.sql

נכנסות רק שורות עם עיר אחת, או "אונליין" (מוסד שמלמד רק אונליין). "כמה סניפים" ו"לא נמצא" נשארים null.
שורה עם slug או עיר שלא נראים תקינים לא נכנסת. היא מופיעה בראש הקובץ ובפלט, כדי שמישהו יבדוק אותה במחקר.
אותו כלל לעיר כמו ב-institutions.yaml (lamadti_scraper.config.CITY) וכמו בבדיקה במסד.
"""

from __future__ import annotations

import csv
import io
import sys
from pathlib import Path

from lamadti_scraper.config import CITY, NOT_A_CITY, SLUG


def city_rows(csv_text: str) -> tuple[list[tuple[str, str]], list[str]]:
    """(slug, עיר) לכל שורה שנכנסת, ומה לא נכנס ולמה. slug שחוזר: השורה הראשונה קובעת."""
    rows: list[tuple[str, str]] = []
    skipped: list[str] = []
    seen: set[str] = set()
    for line, row in enumerate(csv.DictReader(io.StringIO(csv_text)), start=2):
        slug = (row.get("slug") or "").strip()
        city = (row.get("city") or "").strip()
        if city == "" or city in NOT_A_CITY:
            continue
        if not SLUG.match(slug):
            skipped.append(f"line {line}: bad slug {slug!r}")
        elif not CITY.match(city):
            skipped.append(f"line {line}: {slug}: not one city in Hebrew: {city!r}")
        elif slug in seen:
            skipped.append(f"line {line}: {slug}: appears twice, the first row counts")
        else:
            seen.add(slug)
            rows.append((slug, city))
    return rows, skipped


def _literal(text: str) -> str:
    return "'" + text.replace("'", "''") + "'"


def to_sql(rows: list[tuple[str, str]], skipped: list[str], source: str) -> str:
    lines = [
        '-- העיר של כל מוסד (institutions.city), שלב 3 של "לא יודעים למי לפנות?". התוכנית: docs/superpowers/plans/2026-11-19-stage-3-data.md.',
        f"-- נוצר מ-{source} עם scraper/tools/cities_to_sql.py. לא עורכים ביד: מתקנים את המחקר ומריצים שוב.",
        '-- רק מוסדות בעיר אחת, ו"אונליין" למוסד שמלמד רק אונליין. "כמה סניפים" ו"לא נמצא" נשארים null.',
        "-- מעדכן רק מוסד שעוד אין לו עיר: בטוח להריץ שוב, ותיקון ביד לא נדרס. מוסד שעוד לא בטבלה לא משתנה.",
        "--",
        "-- הרצה, באישור של גל, אחרי שהמיגרציה 20261119000001_stage3_data.sql עלתה לענן:",
        "--   pnpm exec supabase db query --remote --yes -f supabase/fixes/2026-11-19-institution-cities.sql",
        "-- בדיקה אחרי, לקריאה בלבד:",
        "--   pnpm exec supabase db query --remote --read-only \"select count(*) filter (where city is not null) as with_city, count(*) filter (where city = 'אונליין') as online from institutions\"",
    ]
    if skipped:
        lines += ["--", "-- לא נכנסו (לבדוק במחקר):"] + [f"--   {s}" for s in skipped]
    values = ",\n".join(f"  ({_literal(slug)}, {_literal(city)})" for slug, city in rows)
    lines += [
        "",
        "update institutions i",
        "set city = v.city",
        "from (values",
        values,
        ") as v(slug, city)",
        "where i.slug = v.slug and i.city is null;",
        "",
    ]
    return "\n".join(lines)


def main(argv: list[str]) -> int:
    if len(argv) != 2:
        print("usage: uv run python -m tools.cities_to_sql <cities.csv> <out.sql>")
        return 2
    source, out = Path(argv[0]), Path(argv[1])
    rows, skipped = city_rows(source.read_text(encoding="utf-8"))
    out.write_bytes(to_sql(rows, skipped, source.as_posix().removeprefix("../")).encode("utf-8"))
    print(f"{len(rows)} institutions, {sum(1 for _, c in rows if c == 'אונליין')} of them online only -> {out}")
    for s in skipped:
        print(f"skipped: {s}")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```
