# האוסף השבועי של למדתי

סקריפט Python שרץ פעם בשבוע ב-GitHub Actions ואוסף פרטי קורסים מהאתרים של המוסדות עצמם. מסמך העיצוב: סעיף 5 ב-`docs/superpowers/specs/2026-11-13-course-comparison-part1-design.md`. התוכנית: `docs/superpowers/plans/2026-11-14-plan-5-weekly-scraper.md`.

## מה הוא עושה, לכל מוסד ב-`institutions.yaml`

1. **מוצא את דפי הקורסים:** ממפת האתר או מעמודי רשימה.
2. **מוריד כל דף:** בבקשה רגילה, ודף שנבנה רק ב-JavaScript נפתח ב-Chromium (Playwright).
3. **משווה לשבוע הקודם:** טביעת אצבע של הטקסט הנראה. דף שלא השתנה לא נשלח למודל.
4. **מחלץ את הפרטים:** `claude-haiku-5-5` ממלא את השדות של `courses`. לכל שדה נשמרים המשפט מהדף ומידת הביטחון.
5. **בודק סבירות ומחליט:**
   - **עולה לבד:**
     - שינוי קטן, למשל מועד מחזור או מחיר שזז עד 20%;
     - שדה שהיה ריק והתמלא, בביטחון גבוה או בינוני, עם משפט שנמצא בדף. מחיר ראשון עדיין עובר לתור.
   - **לתור האישור:** קורס חדש, קפיצה במחיר, סילבוס, הבטחה, ביטחון נמוך, או ערך לא סביר.
6. **כותב למסד בסוף:** עותק לכל דף שהשתנה (`course_snapshots`), שינויים (`course_changes`), התור (`course_change_queue`) ודוח הריצה (`scrape_runs`).

**כשהמודל לא זמין:** הריצה נעצרת בלי לכתוב שום דף, ומנסה שוב בשבוע הבא.

## כללי האיסוף

- **רק מהאתר של המוסד:** האוסף לא יוצא מהדומיין שבהגדרה ומתת-הדומיינים שלו.
- **robots.txt:** מכובד, כולל `Crawl-delay`.
- **קצב:** לכל היותר בקשה אחת בשנייה לכל אתר, גם בדפדפן. אתר ותת-הדומיינים שלו נחשבים אתר אחד.
- **זהות:** `CourseCatalogBot/0.1`, בלי פרטים אישיים.
- **בלי טקסט שיווקי:** ערכי הטקסט מנוסחים מחדש בעברית. המשפט המקורי נשמר רק בעותק הפנימי, לבדיקה.
- **רק דפים שעשויים להיות קורס:** בלוג, חדשות, תגיות, אודות, צור קשר וקבצים מסוננים לפני כל הורדה.
- **רק התחומים שהמוסד אושר בהם:** קורס בתחום אחר (המודל עונה `none`) לא נהיה טיוטה. המודל בוחר תחום לפי השם והתיאור שלו במסד (`categories.description`), ולא מקבל תחום שיצא משימוש (`replaced_by`).
- **תחום שהתחלק:** מוסד שאושר ב-"בינה מלאכותית" מקבל את ארבעת תחומי ה-AI (`SPLIT` ב-`tools/approved_to_yaml.py`).

## איך מוסיפים מוסד

1. **אישור:** גל מאשר אותו. הרשימה הראשונה, שאושרה ב-15.11.2026: `docs/institutions/2026-11-14-proposed-institutions.md`.
2. **ההגדרה:** מוסיפים רשומה ל-`institutions.yaml`, עם `name` ו-`kind`,
     ו-`city` כשיש למוסד עיר אחת (או "אונליין"). העיר נכתבת רק כשהאוסף יוצר את המוסד. הפורמט מתועד בראש הקובץ.
   - **מרשימה שלמה:** `uv run python -m tools.approved_to_yaml <קובץ הרשימה>` כותב את הקובץ מחדש. שורה שמסומנת ❌ לא נכנסת.
3. **בטבלה:** מוסד שעוד לא בטבלה `institutions` נוצר בריצה הבאה.
   - **מה לא משתנה:** מוסד שכבר קיים.
   - **בלי עמוד באתר:** עד שיש לו קורס שאינו טיוטה.
4. **לפני הריצה:** `uv run python -m lamadti_scraper discover --only <slug>` מראה אילו דפים ייקראו, בלי מודל ובלי מסד.

## הרצה מקומית

מתיקיית `scraper/`. צריך [uv](https://docs.astral.sh/uv/). פעם ראשונה:

```bash
uv sync
```

```bash
uv run playwright install chromium
```

**בדיקות:** בדיקות היחידה, ובדיקת שלושה שבועות מול המסד המקומי (אם `pnpm db:start` רץ והמיגרציה הוחלה):

```bash
uv run pytest
```

**הדגמה:** שלושה שבועות של אתר הדוגמה מול המסד המקומי, עם חילוץ מוקלט ובלי מפתח Anthropic. צריך `SUPABASE_URL` ו-`SUPABASE_SECRET_KEY` של המסד המקומי (`pnpm db:status`). ההדגמה מסרבת לרוץ מול מסד שאינו מקומי.

```bash
uv run python -m lamadti_scraper demo
```

**החילוץ האמיתי מול דפי הדוגמה** (עם `ANTHROPIC_API_KEY`, כמה סנטים):

```bash
uv run python -m lamadti_scraper check-fixtures
```

## חילוץ מחדש

אחרי שינוי בהנחיה למודל (`fields.py`, `extract.py`), דפים שלא השתנו לא נקראים שוב לבד. `--reextract` שולח שוב למודל גם אותם, רק של קורסים שמוצגים באתר:

```bash
uv run python -m lamadti_scraper run --reextract --only <slug>
```

בענן: הפעלה ידנית של "Weekly scraper", עם `reextract` מסומן. בדוח: "חילוץ מחדש (--reextract): N דפים שלא השתנו נשלחו שוב למודל."

## אתר הדוגמה

- **מה יש בו:** 20 קורסים מומצאים של "מכללת הדגמה", בשבעה תחומים ובחמישה מבנים של דף. גם דף שנבנה רק ב-JavaScript, דף שאינו קורס, דף שאסור ב-robots.txt, ודף עם ניסיון להטעות את המודל.
- **מקור:** הכול נבנה מ-`tests/fixtures/specs.py`, יחד עם החילוץ הצפוי.
- **בנייה מחדש:** אחרי שינוי במפרט, `uv run python -m tests.fixtures.build`.
- **למה מומצא:** אף מוסד אמיתי עוד לא אושר, ואסור לאסוף ממוסד לפני האישור. דפים אמיתיים יתווספו לבדיקות אחרי האישור של גל.
